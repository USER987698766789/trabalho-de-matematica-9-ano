# Rota dos Polígonos

Trabalho de matemática do 9º ano: um jogo de geometria e álgebra que mostra como a arte moderna se liga à matemática.

**Equipe:** Enrico, Raul, Arthur e Pietro

## O que tem

- Landing page sobre arte moderna e matemática: Mondrian, Kandinsky, Malevich, a arte concreta brasileira e a geometria de Balneário Camboriú.
- Jogo com 5 fases: Ângulos, Perímetro e área, Pitágoras, Sistemas e Desafio final.
- Modo fácil (vidas e dicas infinitas) e modo difícil (3 vidas por fase e 3 dicas no jogo todo).

## Como jogar

Abra o `index.html` no navegador ou acesse o site publicado pelo GitHub Pages.
